# HomeworkTimer for ESP32-S3-Touch-LCD-3.49B

面向儿童家庭作业管理的独立 ESP-IDF/LVGL 工程，适配微雪
`ESP32-S3-Touch-LCD-3.49B`（172 × 640，横屏逻辑分辨率 640 × 172）。

## 功能

- 语文、数学、英语分别开始、暂停、继续和完成计时
- 休息时间独立记录
- NVS 保存各科学习时间、休息时间和完成次数
- 每天记录三科完成状态，跨日自动更新
- 每周一自动换周，并保留上一周数据快照
- 周报显示各科累计、专注总时间及休息时间
- 使用板载 PCF85063 RTC；RTC 无有效时间时以固件编译时间初始化
- 深色星空、彩色渐变卡片风格，适配 640 × 172 长条触摸屏
- 周一至周五课程表，可切换日期查看 7 节课
- 屏幕内扫描 2.4 GHz Wi-Fi、选择网络并通过虚拟键盘输入密码
- 可设置学习闹钟、启用/关闭及切换“工作日/每天”重复模式
- 到点显示全屏提醒并通过板载 ES8311 和扬声器响铃，支持稍后 5 分钟
- Wi-Fi、闹钟和学习记录均保存到 Flash，重新上电后可继续使用
- 内置仅包含界面文字的精简中文字库

已完成的计时段会立即写入 NVS。正在进行但尚未点击“完成”的计时段，断电后不会保留。

## 工程结构

```text
main/
├── app_main.c          启动入口
├── alarm_audio.*       ES8311、I2S 及闹钟提示音
├── alarm_store.*       闹钟设置的 NVS 持久化
├── board_display.*     QSPI 屏幕、触摸、背光及 LVGL 任务
├── rtc_pcf85063.*      RTC 驱动
├── study_store.*       周期计算及 NVS 数据持久化
├── study_ui.*          全部 LVGL 页面与交互
├── ui_font_16.c        精简中文字库
├── wifi_manager.*      Wi-Fi 扫描、连接与状态管理
└── board_config.h      引脚和显示参数
```

LVGL、AXS15231B 面板驱动和 `esp_codec_dev` 音频驱动由 ESP-IDF Component Manager
下载，未把第三方源码复制进仓库。

## 课程表

课程表已直接写入当前有效课表。其中周三第 2 节为语文，周五第 6 节为数学，
这是正式课表内容，界面不会显示临时变更标记。后续如需改课，可编辑
`main/study_ui.c` 中的 `s_schedule`。

## Wi-Fi 与闹钟说明

- 目前支持 2.4 GHz Wi-Fi；网络名称和密码由 ESP-IDF Wi-Fi 驱动保存在 NVS。
- 配网页面会扫描附近网络，开放网络可直接连接，加密网络会弹出屏幕键盘。
- Wi-Fi 当前用于完成本机配网和后续联网功能预留，尚未启用网络自动校时。
- 闹钟使用板载 RTC 判断时间；请先确认设备时间正确。
- 闹钟设置会立即保存，默认时间为工作日 07:00，初始状态为关闭。
- 响铃时可直接关闭，或选择“稍后 5 分钟”。

## 环境

- ESP-IDF 5.4 或更新版本
- 已在 ESP-IDF 6.0.2 下进行构建验证
- 目标芯片：ESP32-S3
- Flash：16 MB
- PSRAM：8 MB OPI

## 构建

在 ESP-IDF 命令行中进入工程目录：

```powershell
idf.py set-target esp32s3
idf.py build
idf.py -p COM15 flash monitor
```

请将 `COM15` 改为设备实际串口。工程首次构建会通过组件管理器下载 LVGL 9.3.0、
`esp_lcd_axs15231b` 2.1.0 和兼容的 `esp_codec_dev` 1.x。

## 后续扩展建议

- 加入 SNTP 自动校时，保留 RTC 作为离线时钟
